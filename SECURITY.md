# Security

This project is documentation and a local linter. It does not run a service.

**Supported versions:** `v0.1.x`. Published tags are not moved. Older untagged trees are unsupported.

**Report a vulnerability** (for example a linter path issue, or a prompt that would cause an agent to commit secrets) via GitHub Security Advisories on this repository, or a private report to the owner. Expect an acknowledgement within a few days on a best-effort basis. Do not file a public issue for anything that could be exploited in adopters’ repos.

Do not put credentials, `.env` values, or personal data in issues, PRs, or knowledge files.
